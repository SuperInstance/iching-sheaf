# iching-sheaf

**Sheaf theory applied to the I Ching** — models the 64 hexagrams as a sheaf on a topological space, with restriction maps encoding line transformations.

## What This Gives You

- **Sheaf structure** — hexagrams as sections over a topological base
- **Restriction maps** — line changes as stalk-to-stalk morphisms
- **Cohomology computation** — structural invariants of the I Ching sheaf
- **Visualization** — render the sheaf topology and cohomology groups

## How It Fits

Part of the SuperInstance mathematical research into applied sheaf theory. Connects to `sheaf-cohomology` and `sheaf-persistence-bundle` for computational sheaf methods.
